# SmithRx

> SmithRx (legal entity Smith Health, Inc.) is a pass-through pharmacy benefit manager (PBM) for self-insured employers, founded by Jake Frenz. It runs an in-house real-time pharmacy claims adjudication platform and a "Drug Pathways Engine" that routes each claim to the lowest net cost pathway across drug selection, source and pricing. SmithRx is URAC-accredited for Pharmacy Benefit Management (PBM010015).

## Machine-readable API surface

**SmithRx publishes no public API.** As of 2026-08-02 there is no developer portal, no API reference, no OpenAPI/Swagger document, no GraphQL endpoint, no AsyncAPI or webhook catalog, no MCP server, and no A2A agent card on any SmithRx host. `api.mysmithrx.com` is a live API host but every probed path returns a plain-text `404 page not found`; it serves the member and partner portals privately. The company's platform marketing describes "secure APIs" used to connect a customer's plan to its existing vendors — that integration surface is partner-gated and not publicly documented.
